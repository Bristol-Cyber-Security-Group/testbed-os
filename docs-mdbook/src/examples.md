# TestbedOS Examples

In the [`examples`](https://github.com/Bristol-Cyber-Security-Group/testbed-os/tree/develop/examples) folder of the [TestbedOS code repository](https://github.com/Bristol-Cyber-Security-Group/testbed-os), there are examples of TestbedOS project that you can try out. 
The `examples` folder contains a subfolder for each example of a TestbedOS project, and the `README.md` file in the folder includes the details for each provided example. 
Please go through the `README.md` file to know more about each example.
Each subfolder in the directory also comes with the `kvm-compose` configuration file and the necessary artefacts to bring up the deployment and interact with it.
This can be done following similar commands in [`Minmal Working Example`](welcome.md#minimal-working-example).
